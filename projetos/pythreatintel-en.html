THREAT INTEL · PYTHON

PyThreatIntel

Is this e-mail phishing, and can you prove it?

A command-line tool that reads an .eml file and returns a threat assessment: sender authentication, spoofing indicators, extracted IoCs and the origin IP's reputation on VirusTotal. Built as a SOC / blue-team project for phishing triage.

Inside the project

From problem to solution

Goal

Turn the feeling that "this e-mail looks weird" into concrete, explainable evidence, in the format a SOC analyst would use during triage.

How it works

The e-mail is read with Python's standard parser. The Received chain is walked from bottom to top until the first public IP, which is the server closest to the sender. Private ranges are filtered out with the ipaddress module.

Security decisions

Only the topmost Authentication-Results header is trusted, since your own server added it. The real domain is taken from the address, not the display name, which defeats the "support@bank.com" <attacker@evil.com> trick. The VirusTotal key comes from an environment variable, never the command line.

Known limitations

Bulk-mail senders (Mailchimp, SendGrid) cause Return-Path false positives. Only the origin IP is checked on VirusTotal; URLs and hashes are not yet. IPv6 support is on the roadmap.
